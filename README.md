# Açaimoc Delivery

Projeto feito para o trabalho de personalização de um site usando HTML, CSS e Bootstrap.

## Sobre o projeto

O site foi adaptado a partir do template Business Casual, que originalmente era uma cafeteria. A ideia foi transformar o modelo em uma açaiteria chamada **Açaimoc Delivery**.

## Páginas

- `index.html` – página inicial e carrossel de imagens.
- `about.html` – informações sobre a Açaimoc.
- `products.html` – cardápio, produtos e montagem personalizada do açaí.
- `store.html` – carrinho e finalização do pedido.

## Pastas principais

- `css/styles.css` – estilos do site e personalizações das cores e componentes.
- `js/scripts.js` – código do carrinho, montagem do açaí e finalização do pedido.
- `assets/img/` – imagens usadas no site.

## Funcionalidades

O visitante pode escolher uma combinação pronta ou montar o próprio açaí. Na montagem personalizada, é possível escolher o tamanho, as frutas e até quatro complementos.

Os produtos escolhidos são colocados no carrinho e o valor total é atualizado automaticamente. Na página de finalização, o cliente informa os dados do pedido e recebe uma confirmação com o número do pedido.
